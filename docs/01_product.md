# Astra AI Platform

## Идея

Astra AI Platform — это платформа для автоматизации общения с клиентами через Telegram с использованием искусственного интеллекта.

Проект предназначен для демонстрации навыков коммерческой разработки и создания сильного портфолио.

---

## Основные возможности

- Telegram Bot
- AI Assistant
- CRM
- REST API
- Административная панель
- База знаний

---

## Целевая аудитория

- Малый бизнес
- Интернет-магазины
- Онлайн-школы
- Фрилансеры
- Консультанты

---

## Основная цель

Получить первые коммерческие заказы на разработку Telegram-ботов, AI-сервисов и backend-приложений.
