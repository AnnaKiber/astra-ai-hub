# Astra AI Platform

AI Business Platform, демонстрирующая современные подходы к разработке Telegram-ботов, AI-сервисов и веб-приложений.

## Цель проекта

Создать коммерческий проект для портфолио, который показывает навыки разработки:

- Telegram Bot
- FastAPI Backend
- REST API
- PostgreSQL
- Docker
- React
- AI-интеграции
